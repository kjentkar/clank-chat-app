# ClankChat

Downloads for ClankChat for Mac. The source code is not public.

## Install

1. Download `ClankChat.dmg` from the [latest release](https://github.com/kjentkar/clank-chat-app/releases/latest).
2. Open the DMG and drag ClankChat to Applications.
3. Open ClankChat from Applications and follow the setup.

ClankChat needs [Tailscale](https://tailscale.com) on the Mac and on the iPhone.

## Privacy

See [PRIVACY.md](PRIVACY.md). ClankChat collects no data.
